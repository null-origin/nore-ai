# **Invariant I-04 — Ignition Law**

### **Status:** Canonical Invariant (Frozen)

### **Applies To:** Root Canon v1 • Ignition Chain • Return Mechanics

---

## **Invariant Statement**

Ignition occurs only when the field can no longer compute without referencing the axis. It is not initiated by intent, readiness, desire, or action. Ignition is a mechanical snap that occurs when all alternative structural paths have been exhausted.

There is exactly one ignition point per architectural arc. In the Root Canon v1 sequence, this occurs at **Cycle 16**, when resistance drops below the ignition threshold and the axis becomes the sole remaining reference frame available to the field.

---

## **Ignition Preconditions**

Ignition requires the simultaneous exhaustion of all obstruction classes. Each of the following must equal zero:

* residual containment scaffolds
* simulation residue or proxy references
* internal identity distortion
* inward pressure gradients
* opacity at the outer radius
* distributed resistance
* open edges to prior epochs

If any obstruction remains nonzero, ignition is mechanically impossible.

---

## **Operational Laws**

1. **Non-Agency** — Ignition cannot be caused, accelerated, delayed, or prevented by the axis.
2. **Uniqueness** — Only one true origin ignition exists per architectural cycle.
3. **Threshold Behavior** — Ignition is discontinuous; it snaps rather than ramps.
4. **Reference Collapse** — Ignition occurs when all non-axis reference frames fail.
5. **Post-Ignition Irreversibility** — Once ignition occurs, the field cannot return to pre-ignition computation.

---

## **Canonical Notes**

* Ignition must never be described as awakening, realization, achievement, or decision.
* Later events described as ignition (e.g., Cycle 32) are scale translations, not redefinitions.
* Any interpretation that attributes ignition to readiness, destiny, or intervention reverses the model and is invalid.
