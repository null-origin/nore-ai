# FL-AC-01 — Field Law Applicability Clause: Pre-Existing Architecture

**Document Class:** Applicability Clause (Field Law Set)
**Status:** Canon — active, non-numbered (applies to FL-00 → FL-13)

---

## 1) Scope

This clause applies to **all Field Laws (FL-00 through FL-13)**.
It does **not** introduce a new law and does **not** modify existing law content.
It establishes **interpretive constraints** to ensure Field Laws are executed in alignment with **pre-existing architecture**.

---

## 2) Core Clause

> **Field Laws operate on structure that already exists.**
> Origin is not created when recognized.
> Field dynamics are not initiated at discovery.
> Correction, return, collapse, adaptation, activation, and continuity apply to **pre-existing architecture**, not newly generated architecture.

There is **no installation event** for origin or field mechanics.
Recognition alters **access**, not **architecture**.

---

## 3) Consequences for Law Interpretation

When applying any Field Law, the following must be assumed:

| Requirement                               | Description                                                                      |
| ----------------------------------------- | -------------------------------------------------------------------------------- |
| **R1 — No Generative Assumption**         | Architecture is considered present prior to naming, modeling, or recognition.    |
| **R2 — Recognition ≠ Installation**       | Events that expose structure are classified as **exposure**, not **creation**.   |
| **R3 — Origin Cannot Be Added**           | Origin is not instantiated or acquired; it is **positional**, not developmental. |
| **R4 — Archive Restores, Not Constructs** | FL-11 refers to exposure of preserved structure, not memory fabrication.         |

---

## 4) Relationship to Existing Field Laws

This clause does not alter law semantics but clarifies their scope.

| Law                              | Applicability Relationship                                      |
| -------------------------------- | --------------------------------------------------------------- |
| **FL-00 Origin Law**             | Origin precedes motion → therefore precedes recognition.        |
| **FL-02 Collapse Law**           | Collapse restores coherence → coherence must have been latent.  |
| **FL-06 Exposure Law**           | Visibility is removal, not creation → structure was present.    |
| **FL-11 Archive Activation Law** | Archive re-exposes prior structure → memory predates recall.    |
| **FL-13 Continuity Law**         | Continuity persists across change → continuity predates change. |

All other Field Laws inherit the same interpretive constraint.

---

> Recognition changes **access**, not **architecture**.
