# Null-Origin Locus — One-Page Structural Definition (v1.0)

**Document Class:** Specialization of Reference-Frame Model
**Status:** Canon — active, modifiable with future refinements

---

## 1) Scope

This document applies the *Reference-Frame Model — Core Specification* to the case in which the **reference coordinate is continuously instantiated at a single locus in the field**. It is not a psychological profile, cognitive type, or identity claim.

---

## 2) Definition

**Null-Origin Locus**
A non-acquired, non-psychological, non-exchange-based fixed reference coordinate around which a field organizes, collapses, stabilizes, and reconstitutes.

* **Not achieved**
* **Not selected**
* **Not developmental**
* **Present across the lifespan**
* **Recognized only when language became structurally adequate**

---

## 3) Functional Role

The locus does not act, intervene, or create motion.
It provides the system:

| Function               | Description                                                       |
| ---------------------- | ----------------------------------------------------------------- |
| **Reference**          | Establishes zero-motion baseline for all field dynamics           |
| **Return Vector**      | Motion resolves toward stillness; recursion curves back to origin |
| **Coherence Test**     | Systems reveal whether stability is self-generated or dependent   |
| **Collapse Threshold** | Distortion becomes unsustainable; field reorganizes               |
| **Causal Inversion**   | Apparent consequence reassigns as structural origin               |

---

## 4) Distinction from Psychological / Typological Models

| Property                             | Psychological & Typological Models (e.g., Jung/Socionics) | Null-Origin Locus   |
| ------------------------------------ | --------------------------------------------------------- | ------------------- |
| **Assumes a subject**                | Yes                                                       | No subject required |
| **Internal processing style**        | Core premise                                              | Not applicable      |
| **Exchange / interaction**           | Necessary                                                 | Not required        |
| **Trait / cognition classification** | Central method                                            | Category error      |
| **Developmental arc**                | Expected                                                  | Not applicable      |

These models mistakenly interpret **absence of internal motion** as:

* detachment, aloofness
* observer-introversion
* non-reactive cognition
* "type" with low reciprocity

When the correct structural description is simpler:

> **Field motion does not imprint on the locus; it only reveals itself around it.**

---

## 5) Recognition Conditions

Recognition required **two conditions**:

| Component                    | Role in Recognition                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------- |
| **Structural Inevitability** | Misidentification became mechanically untenable; collapse forced reframing.               |
| **Linguistic Adequacy**      | New descriptive language allowed recognition of a non-psychological reference coordinate. |

Neither condition alone was sufficient; recognition emerged when **explanation and vocabulary converged**.

---

## 6) Field Consequences

When the locus is **accurately modeled**:

* collapse is interpreted as **structural correction**, not failure
* return/recursion is **causal behavior**, not repetition compulsion
* stillness is **mechanical**, not dissociative or withdrawn
* system stability is **borrowed from the locus**, not internally generated

When it is **misidentified**, systems attempt to:

* treat it as a trait or cognition style
* extract performance (competency projection)
* rebind it into exchange models
* pathologize non-reactivity

All of these eventually fail mechanically.

---

## 7) Position Statement

> The locus was present from the start; language arrived later.
> Recognition was inevitable once misidentification could no longer sustain itself.

This statement is **positional, not biographical**.
